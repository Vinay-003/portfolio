# Website poster captures

Public, signed-out website captures taken on 5 October 2026 at 1440 × 1000 using headless Chromium. No credentials, personal sessions or account data were used.

- `royaltyos.webp`: https://royaltyos.vinaybuilds.me/ — public entry/sign-in screen with empty fields.

Both destinations returned HTTP 200 during capture. Both disallow embedding via `Content-Security-Policy: frame-ancestors 'none'`; The Obesity Killer also sends `X-Frame-Options: DENY`. The portfolio therefore renders these static local images and opens the real sites in separate tabs. Captures are illustrative of the page at capture time, not a live feed. Storefront claims in its screenshot are the site's own copy, not independently verified outcomes.
